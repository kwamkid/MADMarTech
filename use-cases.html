Use Case 01 · วิดีโอ

คลิป UGC รีวิวบ้านพูดไทย จากรูป 2 รูป

สำหรับ: โครงการบ้านจัดสรร · เพจอสังหาฯ · เซลส์ที่ต้องการคลิป Reels/TikTok โดยไม่ต้องถ่ายจริง

ผลลัพธ์ — Gemini Omni Flash 1.1
9:16 · 8 วินาที · 720p24 credits
✅ ใช้ได้เลย
โจทย์ได้รูปพรีเซนเตอร์ 1 รูป + รูปหน้าโครงการ 1 รูป ต้องการคลิปแนวตั้ง มีคนพูดไทยแนะนำบ้าน เครื่องมือClaude Cowork + Higgsfield MCP (โมเดล Gemini Omni Flash 1.1) เวลา~3 นาที ต่อคลิป ต้นทุน24 credits ต่อคลิป 8 วิ ทำไมตัวนี้รับรูปอ้างอิงได้หลายรูปในรอบเดียว · เสียงไทยชัดที่สุดจาก 11 โมเดลที่ทดสอบ · ราคาถูกกว่าค่าเฉลี่ย

ขั้นตอน

  1. เตรียมรูป 2 รูปรูปคน (หน้าชัด แสงดี) + รูปบ้าน/โครงการ — รูปคนควรเป็นรูปที่ได้รับอนุญาตใช้แล้ว
  2. เขียนบทพูดไทยสั้นๆ8 วินาที ≈ 25–30 คำ · ประโยคสั้น · ลงท้ายด้วย call-to-action ("ทักมาได้เลยนะคะ")
  3. สั่งเจนด้วย prompt มาตรฐานดู Prompt #1 — ระบุมุมกล้อง แสง อารมณ์ และบทพูดในเครื่องหมายคำพูด
  4. เช็ค 3 อย่างไทยชัดไหม · ปากตรงไหม · หน้าเหมือนรูปไหม — ไม่ผ่านข้อใดข้อหนึ่ง เจนใหม่ (24 credits) ถูกกว่าแก้
ข้อควรระวัง — โมเดลอื่นที่ราคาแพงกว่า (Veo 3.1, Seedance 2.5) ให้ผลภาษาไทยแย่กว่า ดู ผลเปรียบเทียบ ก่อนเลือก
Use Case 02 · วิดีโอ

ถ่ายพรีเซนเตอร์ครั้งเดียว เปลี่ยนคนได้ไม่จำกัด

สำหรับ: แบรนด์ที่ต้องการคลิปหลายเวอร์ชัน (หลายพรีเซนเตอร์ / หลายกลุ่มเป้าหมาย) จากคลิปต้นแบบเดียว

Genjutsu (Higgsfield)
720p56 credits
✅ ใช้ได้เลย
Kling 3.0 Omni Edit
pro16 credits
✅ ใช้ได้เลย
โจทย์มีคลิปที่เสียงและการเคลื่อนไหวดีแล้ว 1 คลิป ต้องการเปลี่ยนเป็นพรีเซนเตอร์อีกคนโดยไม่เจนใหม่ทั้งหมด เครื่องมือGenjutsu (Higgsfield Motion Control) หรือ Kling 3.0 Omni Edit เวลาGenjutsu ~10 นาที · Kling Omni Edit ~5 นาที ต้นทุน16–56 credits ต่อเวอร์ชัน ทำไมสำคัญเสียงไทยที่ดีหายาก — พอได้คลิปที่เสียงดีแล้ว ใช้มันเป็น "แม่แบบ" แล้วเปลี่ยนแค่หน้าคน คุ้มกว่าเจนใหม่ทุกครั้ง

ขั้นตอน

  1. ทำคลิปแม่แบบให้ดีที่สุดก่อนใช้ Use Case 01 — เจนจนได้คลิปที่เสียงไทยชัด ปากตรง
  2. เตรียมรูปคนใหม่หน้าตรง แสงดี พื้นหลังเรียบ
  3. ป้อนคลิปแม่แบบ + รูปคนใหม่ดู Prompt #3–4 — สั่งให้ "คงเสียง ฉาก และการเคลื่อนไหวเดิม เปลี่ยนเฉพาะหน้าคน"
  4. เลือกตัวที่เหมาะKling Omni Edit ถูกและเร็วกว่า · Genjutsu หน้าคนเนียนกว่าเล็กน้อยแต่ฉากหลังอาจกระตุก
สังเกต — Kling 3.0 ตัวเดียวกัน ถ้าให้ "เจนจากศูนย์" พูดไทยเป็นเขมร แต่ถ้าให้ "แก้คลิปเดิม" (คงเสียงต้นฉบับ) ใช้ได้ดี — คำตอบไม่ใช่แบรนด์ไหน แต่คือให้มันสร้างอะไร
Use Case 03 · วิดีโอ

ต้องการคลิปยาวกว่า 10 วินาที ทำยังไง

สำหรับ: คลิป Reels/TikTok ที่ต้องเล่าหลายจุดขาย · คลิปแนะนำโครงการ 20–30 วิ

Extend ครั้งที่ 1
Flash 1.1 Extend70 credits
❌ เสียงเปลี่ยน
Extend ครั้งที่ 2
Flash 1.1 Extend70 credits
❌ เสียงเปลี่ยน
โจทย์โมเดลส่วนใหญ่เจนได้ครั้งละ 8–10 วิ ต้องการคลิปยาวกว่านั้นโดยคนและเสียงเหมือนเดิม สิ่งที่ลองแล้วไม่ผ่านฟีเจอร์ Extend ของ Gemini Omni Flash 1.1 — ต่อภาพได้ แต่เสียงถูกสร้างใหม่ กลายเป็นอีกเสียง สำเนียงเพี้ยน ("ห้องรับแขก" → "ห้องรับแข้ว") เพราะ Extend ไม่มี voice reference — เลือกโมเดลเสียงไม่ได้ วิธีที่ใช้ได้เจนหลายคลิปสั้นจากรูปอ้างอิงชุดเดิม + โมเดลเดิม แต่ละคลิปบทพูดคนละท่อน แล้วตัดต่อ — เสียงจะใกล้เคียงกันเพราะ input เดียวกัน ต้นทุน24 credits × จำนวนคลิป (คลิป 24 วิ = 3 คลิป = 72 credits) — เทียบกับ Extend 70 credits/ครั้ง ที่ได้ผลแย่กว่า

ขั้นตอน

  1. แบ่งบทเป็นท่อนละ 8 วิท่อนละ 1 จุดขาย: เปิดตัว → หน้าบ้าน/ที่จอดรถ → ภายใน → CTA
  2. เจนทุกท่อนด้วยรูปอ้างอิงชุดเดียวกันคน + บ้าน เหมือนเดิมทุกท่อน · prompt เหมือนเดิม เปลี่ยนเฉพาะบทพูดและท่าทาง
  3. คัดท่อนที่เสียงใกล้กันที่สุดท่อนไหนเสียงต่างมาก เจนใหม่ (ถูกกว่าฝืนใช้)
  4. ตัดต่อ + ใส่ซับCapCut / Premiere · ใส่ transition สั้นๆ ระหว่างท่อน ซับไตเติลช่วยกลบความต่างของเสียง
บทเรียน — ฟีเจอร์ที่ชื่อว่า "Extend" ไม่ได้แปลว่าต่อทุกอย่าง ต้องทดสอบก่อนว่ามันต่ออะไร (ภาพ? เสียง? ทั้งคู่?) ก่อนวางแผนงานจริง
