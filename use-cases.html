ขั้นตอน

  1. เตรียมรูป 2 รูปรูปคนหน้าชัด + รูปบ้าน — รูปคนต้องได้รับอนุญาตแล้ว
  2. เขียนบทพูดไทยสั้นๆ8 วิ ≈ 25–30 คำ · ลงท้ายด้วย CTA
  3. สั่งเจนด้วย prompt มาตรฐานดู Prompt #1 หรือ แกะทีละส่วน
  4. เช็ค 3 อย่างไทยชัด · ปากตรง · หน้าเหมือน — ไม่ผ่านเจนใหม่ ถูกกว่าแก้
ข้อควรระวัง — โมเดลที่แพงกว่า (Veo 3.1, Seedance 2.5) ให้ผลภาษาไทยแย่กว่า ดู ผลเปรียบเทียบ ก่อนเลือก

ขั้นตอน

  1. แบ่งบทท่อนละ 8 วิท่อนละ 1 จุดขาย: เปิดตัว → หน้าบ้าน → ภายใน → CTA

  4. ตัดต่อ + ใส่ซับCapCut / Premiere · ซับช่วยกลบความต่างของเสียง
